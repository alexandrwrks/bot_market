Телеграм бот для покупки спорт товаров. Пользователь нажимает на кнопку каталог там варианты категорий,
после выбирет нужную ему категорию и покупает товар n-шт по стоимости k рублей. Товары/ы добавляются в 
корзину, которую пользователь может открыть, посмотреть и удалить не нужные ему товары. 

Админ - создаёт товары для бота, полностью отдельная панель с созданием товара, проверкой наличия товара 
в БД, изменение количества и стоимости товара
