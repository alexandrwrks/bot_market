# SportMarket Bot

Telegram-магазин спортивных товаров с CRM-панелью для менеджеров.

## Возможности

### Пользователь

* Просмотр каталога товаров
* Просмотр категорий
* Добавление товаров в корзину
* Оформление заказа
* Просмотр своих заказов
* Передача контактных данных менеджеру

### Менеджер

* Просмотр заказов
* Просмотр статистики
* Управление товарами
* Управление категориями

### CRM

* Дашборд со статистикой
* Просмотр пользователей
* Просмотр заказов
* Управление товарами
* Управление категориями

## Установка

### 1. Клонировать репозиторий

```bash
git clone <repository_url>
```

### 2. Создать виртуальное окружение

```bash
uv init
```

### 3. Установить зависимости

```bash
uv sync
```

---

## Настройка переменных окружения

Создайте файл `.env` в корне проекта с помощью `copy .env.example .env`:
```env
BOT_TOKEN=your_bot_token

DB_HOST=db_host
DB_PORT=db_port
DB_USER=db_user
DB_PASSWORD=db_password
DB_NAME=da_name

REDIS_HOST=redis_host
REDIS_PORT=redis_port

ADMIN_IDS=list_of_telegram_ids
```

---

## Запуск проекта

### Telegram Bot

```bash
python -m app.bot.main
```

### CRM

```bash
python -m app.api.main
```

После запуска CRM будет доступна по адресу:

```text
http://0.0.0.0:8000
```

## Пользовательский сценарий

1. Запустить бота через `/start`
2. Открыть каталог
3. Выбрать категорию
4. Выбрать товар
5. Указать количество
6. Добавить товар в корзину
7. Оформить заказ
8. Указать имя и номер телефона
9. Дождаться ответа менеджера
10. Получить заказ
